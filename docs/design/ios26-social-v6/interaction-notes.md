# v6 交互约定补充

2026-09-12 根据设备反馈更新；与早期设计图冲突时，以本约定为准。

- 地图 Activity 面板只保留拖动把手，不再显示展开／收起箭头。收起时点标题展开；展开时点把手收起，继续支持拖动。保留 44pt 点按范围与读屏的展开状态。
- 进入子页面后的“返回”统一放在左上角，使用共用圆形玻璃 BackButton。右上角用于搜索、更多或明确的关闭操作，不用右上角返回箭头。
- 示例会话与真实会话遵循同一返回布局；消息请求、互动、评论回复和相关详情页也遵循同样规则。
- 页面跳转的列表行可保留行尾指示，不与页面返回或面板展开混用。玻璃材质跟随系统减少透明度设置。
