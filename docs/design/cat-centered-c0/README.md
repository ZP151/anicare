## 页面决定

- 猫主页：公开猫照片、名字、邻里和档案身份先出现；照片从现有 356pt 大头图收紧为约 215pt，让故事标题与第一位作者更早可见。主动作“分享与它的相遇”固定在底部。关注在名字右侧；身份资料、目击和照护各有入口，纠错在更多操作内。
- 故事以纵向内容流呈现，作者在每篇正文前，照片只来自原帖附件。猫的封面照片不能冒充文字故事的附件。C1 不先加空相册标签，不展示未经真实读取的故事总数。
- 发布复用六格、编辑与排序；邻里行上方新增选猫行。选猫面板先选择高亮、再确认，关闭不改变草稿。路由预选可替换；未知或多猫照片可不选猫，但必须有邻里。
- 发布结果只保留明确出口：关联猫时以猫主页为主、原帖为次；未知时以原帖为主，可稍后补关联。不在成功页叠加回执式状态清单。
- 档案的“身份状态”与“由作者关联的故事”分别标示。故事只是作者的关联声明；不为此写入身份、目击或照护记录。作者更正在原帖更多操作内；第三方保留举报／纠错，不显示直接改关联动作。
- 旧照片显示发布信息，正文可以说明相遇时间，不能用上传时间生成“刚刚目击”。没有故事只说没有公开故事，不能推断猫的现状。

## 状态与走读

走读顶部有五种场景及浅深色、大字号开关；窄屏通过三个页签切换目标页面。

1. 已知猫：橘子主页显示 Mei、Daniel 两位演示作者；点作者解释资料入口，点故事解释原帖入口。分享预选橘子，打开选猫面板，换小白或取消后确认；发布按钮仅切换到结果预览，不产生网络写入。
2. 未知猫：选“暂不确定”，保留六格与文字，明确邻里必选；结果回原帖，后续补关联入口保留。此走读已预填西海岸，真正定位沿用现有实现。
3. 无故事：标题“还没有公开故事”，主按钮仍可分享，不伪造历史贡献。
4. 读取失败：猫的身份仍在，故事区局部重试，不将失败当成空列表。
5. 关联不可用：发布禁用，照片和正文保留；改选猫或暂不关联后才恢复发布。此结果页仍是布局预览，不能当作已成功写入。

图稿中的照片格操作、资料／照护／目击／原帖出口以明确说明表示复用边界，不假装新接口已接通。关注仅为本地演示切换。相册、关注更新流属于 C2/C3，不在 C0 偷接空壳。

## 视觉与实现边界

应用继续复用 native-colors：浅色 canvas #F5F5F7、surface #FFFFFF、ink #1C1C1E、action #2465D8；深色沿用现有 token。主标题 24pt、正文 15pt、署名 14pt、辅助 12pt；最小触控 44pt，字号增长后允许流式换行。选猫照片 65pt，仅选中时出现浅蓝背景；避免多个整行蓝色实心按钮竞争。

浏览器稿用于布局与状态走读，原生导航、键盘、手势、VoiceOver 与动态字号仍由 C1 原生实现和设备证据验证；不以网页模拟证明 Liquid Glass。大字号开关只是压力预览。中文稿的对应英文操作为 Share an encounter / Choose a cat / Not sure yet / View cat stories / View original post / Change cat link。
