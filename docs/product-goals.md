## 定位与北极星指标

**产品承诺：识别同一只社区猫，理解真实完成的照护，安全地传承记录并纠错。** AI 帮助候选查找，人类确认身份。

建议内部试用验证指标：**14 天内由至少两位贡献者产生有效连续记录、具有独立确认身份及至少一条有效完成照护事件的猫数。** 两位贡献者须各自产生有效 sighting 或 care 记录，单纯审核动作不计入贡献人数。这是新的待验证价值指标，当前未测；不是已经存在的运营事实，也不替代章程的正式试点成功条件。

章程原目标仍保留：至少 30 只具独立身份审核记录的常驻猫、试点第 8 周至少 20 位每周贡献者、审核响应约定、既定 AI 三指标和零未解决关键精确位置暴露。真实试点未开始前不填达成率。产品重心取舍是先交付内部人工闭环、AI 有界验证，未批准跳过 AI 正式 MVP 条件。

## 指标口径与最小取数

不先建分析平台或加入第三方追踪 SDK。优先从受权限保护的服务端账本/请求状态统计聚合数；用户体验试验由自愿参加者按同一任务记录完成情况。记录测试数据域与真实用户数据域，不能混算。

| 指标 | 分子 / 分母或时间边界 | 来源与排除项 |
| --- | --- | --- |
| 身份闭环完成率 | 窗口内提出有效身份请求且在约定观察期得到已关联档案的报告 / 同批有效身份请求报告 | sightings + proposals + resolved animal + review；去重 requestId；skip、测试数据、用户删除单列，不偷偷从失败分母去掉 |
| 新猫建档成功率 | 成功创建且可按权限读取档案的新猫确认事务 / 所有有效显式建档尝试 | M1.2 事务结果；重放只算一次，拒绝/失效/内部错误分类 |
| 北极星猫数 | 最近 14 天符合独立身份确认、至少两位有效贡献者及有效完成照护的 distinct animal 数 | 受信聚合现有/新增账本；更正/撤回后的无效事实不计；只输出聚合，不导出账号/位置 |
| 有用回访率 | 激活后 7 天内回访且读到/新增有效记录或完成更正的人数 / 有完整 7 天观察期的激活人数 | 初期合成试验只记场景结果；真实产品需最小目的限定事件或自愿试验记录，当前无遥测不可推算 |
| 审核时长 | request created → 首次有效处理/最终决定，分别报告中位数、P95 和未结案数 | 私有 queue/review；不能只统计已完成而隐去堆积；严重等级分别统计 |
| AI 效果 | 按固定 animal-disjoint/open-set holdout 计算既定三指标，附样本数与未知比例 | 许可 manifest + 冻结评估；不以训练集或合成契约得分充当质量 |
| 回归/交付效率 | 依赖就绪后的核心运行时间；首次变更→可演示→合入→候选各时间 | 测试输出/CI；本地/CI、冷/热缓存分开，10 次可比样本后才报 P95 |

取数实现随相应 M1/M2/M4 功能一起交付；当前表格是确定口径，不表示已有事件采集、dashboard 或自动周报。主张“识别更快”必须先有人工基线及候选辅助的同任务结果。
