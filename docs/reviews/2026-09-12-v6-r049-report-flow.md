# 0.4.9（17）· 报告流程与返回恢复

用户确认地图与其余功能通过，本轮集中报告流程，不调整已通过的地图与原生玻璃导航。

## 实现

- 五步统一紧凑页头、44pt 返回入口、进度条和固定底部动作；第二步明确分为外观特征与当前状态，缩短毛色/特征标签。确认页补充已选外观与备注。中文公开范围和区域文案保持简明。
- 第四步首次进入自动获取设备位置。已有手选区域、地图发起的手动模式和仍有效的设备位置不被覆盖；拒绝定位自动显示手选地图。晚到定位、后台失效和返回后的重试继续使用原有内存坐标隔离，草稿不持久化精确坐标。
- 提交完成使用 replace 前往回执，避免回退到已转换成回执锚点的旧编辑页。仍遇到旧路由时，仅 owner 一致、无报告正文且包含合法 sighting ID 的锚点恢复到回执；跳转前复核账户。包含待恢复媒体的草稿继续可编辑。
- 相似猫头像先选中，高亮外圈；展示名字、公开核验状态和近期活动时间。照片可放大查看、双指缩放、平移及点击关闭，关闭按钮在安全区内。单独确认按钮才保存身份建议及提交；原 durable UUID 重试和独立审核语义不变。
- 回执不再重复计算原生导航条与内容的顶部 inset；报告编号/提交时间仍在详情中。

## 验证

先加入自动定位、锚点恢复和显式选猫用例，确认旧行为失败；随后补充连续前后返回、手选抵消迟到 GPS、跨账户锚点拒绝、恢复中账户切换、保留媒体恢复草稿、查看大图不提交、确认最后选择，以及路由 replace/push 区分。

目标测试、独立只读审查与完整 `pnpm verify` 均通过：128 个移动端套件、1124 项测试，以及工作区类型检查、lint、测试与构建。云端构建结果在交付后补录。原生触摸效果及本机权限交互仍需本次 iPhone 验收。
