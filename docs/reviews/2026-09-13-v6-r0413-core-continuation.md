## 帖子详情

真实点赞状态与计数接入详情，失败显示重试而非伪造零计数；猫卡与粗粒度邻里集中在正文附近。文字帖不再拿猫头像冒充帖子附件。作者摘要使用当前公开头像、姓名和已有私信能力，消息操作绑定当前显示的帖子，避免迟到路由造成错发对象。离开页面后点赞响应不能更新旧组件。

## 评论续聊

独立讨论页保留原帖摘要、父评论及回到原帖入口。通知准确进入父评论或指定子回复，超过第一页的回复也可直接定位，分页不重复显示。隐藏、删除、屏蔽后的内容遵守既有可见性边界；通知目标失效不会错误跳到别的帖子。分页失败保留已读内容，旧讨论的迟到失败不能破坏新讨论重试。详情返回焦点时重新读取内容。

新增 `get_public_community_reply(uuid)` 仅返回既有公开六字段，使用现有回复可见性函数；不增加私人作者 ID 或绕过父帖/父回复屏蔽规则。

## 到期媒体维护

修复清理任务 ID 与媒体 ID 混淆造成真实任务被跳过的问题。claim 明确返回两类 ID；路径绑定媒体 ID，完成请求仍绑定清理任务及当前租约。错误路径、旧租约和删除失败有独立回归。

每15分钟的私有 pg_cron 函数通过 pg_net 调用固定清理入口。Vault 与 Edge 使用同一个专用随机密钥，队列只保存带用途域、时间、nonce 的短时 HMAC；不保存原始密钥或 service-role。保留人工维护及账号删除使用的服务端调用。部署先配置 Edge secret、成功部署函数并核对库存，再激活 Vault，首次中断可重跑恢复。

pg_net 扩展内部队列由 `supabase_admin` 管理，普通部署角色无法改变其默认权限。本轮没有宣称队列 ACL 隔离，也不改变扩展所有权。签名允许过去300秒、未来30秒；nonce 不提供有状态的防重放。短窗口内的重复请求仍受无目标参数、25项批量上限、到期状态和租约约束。当前 PostgREST 没有公开 net schema 或任意 SQL 桥。

云端验证创建当前 workflow attempt 的可恢复合成 ID、已到期和未到期的四个真实对象；关联实际 HTTP 响应及完成数，再验证到期对象不存在、未到期对象字节和数据库记录完全不变。最后及工作流 always 步骤分别回收四个精确路径；任何验证或回收失败都阻止凭据产出。该检查验证回收链路，不代表长期运行监控。
