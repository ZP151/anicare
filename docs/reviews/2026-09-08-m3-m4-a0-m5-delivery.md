## 必要修复与验证边界

M3 的关注重放固定回执而不重复写入；隐藏/删除目标安全失效。发现与 Following 复用公开猫摘要，屏蔽后无活动的可公开空档案行为保持一致。

M4 新迁移 `202609080007_user_rights.sql` 保留 owner/private 边界和服务端删除特权。Auth 删除时，在已有触发器清理/置空所有者前后分别关联暂存和旧媒体作业。人工删除 profile 不能被当成 Auth 已删除。预删除 JWT 不能继续读取权利状态；移动端只清理发起请求的同一会话，旧请求错误不会退出新账户。

待确认请求使用本人 SecureStore、稳定请求 ID 和串行/CAS 操作。响应丢失后可重开重试；停止本机重试不撤销服务器已接收请求，也不能清掉另一页面新保存的请求。本地删除回执仅含 requestId 和接收状态，无正文/账户信息；它不证明后台已经全量删除。

C09 是本地分层验证：实际 Admin processor/action 单测验证 Auth API hard delete 及既有两类 cleanup handler 调用；028 在 PostgreSQL 删除合成 Auth 行，验证触发器/账本，再调用实际既有清理完成 RPC。没有把 SQL DELETE 或 mock HTTP 宣称为 hosted Auth/Storage HTTP、真实照片或设备端到端验收。

R0A 去掉错误的 `--no-public-good` 排除，保留 repo/workflow/SLSA/hosted runner/source ref/signer 和 source digest 限制；acquisition 另精确绑定 JSON 内 source/run/attempt。新增只读 smoke CLI 不写 evidence。source inventory 纳入根 verify 一次；继续沿用前批 CI 同 job 去重，不另加网络 smoke 为每次迭代前置。
