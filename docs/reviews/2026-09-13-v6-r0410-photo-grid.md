# 0.4.10（18）· 六图展位与拖动排序

本轮按用户要求丰富分享帖编辑照片区：固定两行三列、六个独立圆角展位，12pt 格间留白与照片内边距。空位可添加，已选照片保留封面与删除操作。

长按照片 280ms 后拖动，其他图片预览补位、目标展位高亮；松手后才更新草稿顺序。第一张继续作为封面。拖出网格或手势取消时回到原位。提供屏幕阅读器向前/向后移动操作。普通滑动仍滚动页面，拖动期间锁住滚动与发布/关闭，结束后恢复。

使用现有 Gesture Handler / Reanimated / Worklets 依赖：连续位移在 UI 线程运行，RN 仅在手势开始/结束接收状态与排序提交；回弹遵循系统减少动态效果。没有引入新包。顺序变更沿用原草稿版本保存、图片 ID 与上传顺序，不重建图片或丢失加密媒体。

先验证旧实现缺少空位和顺序保存，再补充跨行拖动成功/取消、网格外落点、首尾移动、无障碍换位和退出账户后的迟到回调。目标 27 项测试通过；独立审查发现并已修复原生滚动与拖动竞争：外层 ScrollView 注册 Native 手势，照片 Pan 建立 blocksExternalGesture 关系，避免只依赖 React 状态锁滚动。相关回归先失败后修复，最终复核无阻断；完整 `pnpm verify` 退出码 0：移动端 129 套件 / 1,142 测试通过，工作区 lint、typecheck、tests、build 均通过。安装包已核验，见下方构建记录。真实 iPhone 长按、拖动与滚动交接仍需本次验收。

实现参考现有依赖 API 及官方 [Pan 手势](https://docs.swmansion.com/react-native-gesture-handler/docs/2.x/fundamentals/gesture-composition/) / [工作线程调度](https://docs.swmansion.com/react-native-worklets/docs/0.9/threading/scheduleOnRN/)。
