## 执行约束与判断

- 只在 `codex/hosted-gate-2b` 的现有隔离工作树实施，保留主工作区的用户修改。
- UI 和照片数据接入共享猫卡/档案接口：先完成 UI，再串行集成照片适配，不让两个实施者同时改写同一工作树。
- 87 张图是路由与状态的参考，不创建 87 个发布门禁。状态与流程沿用现有业务事实；尚不支持的功能不做假按钮。
- 已有真实公开猫优先。若素材不足，以明确标注的合成样本补齐指定测试环境，禁止重置数据库或覆盖真实猫的历史。
- 用户已要求连续推进至可上机候选；沿用现有受保护构建和分发链路。只有实际失败或外部必需信息缺失才报告具体阻碍。
- 不声称 CSS 图稿证明了 iPhone 原生材质；下一次用户真机测试验证玻璃、滚动、键盘及功能闭环。

## 真机测试顺序

1. 冷启动浏览有照片的猫，切区域、打开地图和同一档案。
2. 登录后关注，再重开应用确认；取消关注验证更新。
3. 新增目击，保存草稿并恢复；查看真实回执。
4. 新增已完成照护，查看本人记录与公开历史的实际发布时间。
5. 修改个人资料；切深色、减少透明度和大字号；检查玻璃控件、键盘与返回。
