原有四张图片仅用于明确标注的合成测试猫。橘猫沿用项目已有演示素材；白猫、狸花猫、黑白猫于 2026-09-08 使用 OpenAI image_gen 生成。不存在对应的真实猫身份、真实目击或真实社区确认。

2026-09-11 使用内置 imagegen 新增八张场景图与两张虚构成年邻居头像，逐张生成并检查。场景涵盖侧面、背影、低光运动模糊、树叶遮挡、清晰单猫、两猫及三猫。多猫图只用于社区相册。人物是合成角色，不对应真实账号；客户端仅为固定测试帖显示这些头像。提示记录见 [generated-v6-prompts.md](generated-v6-prompts.md)。

新增图以完整构图编码为 sRGB baseline JPEG，质量 88，不裁剪或修饰，去除元数据。另产生完整构图的 480px 缩略图。原始图与缩略图的尺寸、字节与摘要均在 asset-provenance.json；客户端两个头像副本对应 avatar-woman-thumb.jpg 与 avatar-man-thumb.jpg。

已检查：画面没有可识别人物、车牌、路牌或精确位置标识。保留原始构图，只转为 sRGB JPEG（质量 88，移除元数据），用于私有测试照片桶。来源、尺寸与 SHA-256 记录在 asset-provenance.json。

这些素材不写入普通用户上传的 media_assets，不解除既有照片的隔离状态，不作为 AI 识别效果或社区真实活跃量的证据。公开真实猫照片的授权流程须独立完成。
